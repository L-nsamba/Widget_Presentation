# Flutter Widget Presentation
A simple Flutter app demonstrating the BottomNavigation Widget

## Set Up
1. Clone the repository
2. Open the project in VS Code or Android Studio
3. Run `flutter pub get`
4. Connect to emulator or physical device
5. Run the app using `flutter run`

## Attributes Demonstrated
- **items:** Defines the navigation options, including their icons and labels.
-  **currentIndex:** Determines which navigation item is currently selected.
-  **onTap:** Handles user taps and updates the selected navigation item
